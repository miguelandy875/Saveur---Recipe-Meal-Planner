# Rapport LaTeX - Saveur

This folder contains the academic report source for the Saveur exam project.

## Files

- `main.tex`: full LaTeX report following the lecturer model.
- `figures/`: place screenshots here before the final PDF export.

## Compile

Use Overleaf, MiKTeX, TeX Live, or any LaTeX distribution.

Recommended local commands:

```bash
pdflatex main.tex
pdflatex main.tex
```

Run the command twice so the table of contents and figure references update correctly.

## Before Submission

Edit these placeholders in `main.tex`:

- Student names
- Institution and department
- Lecturer name
- Submission date
- Real screenshots in `figures/`
